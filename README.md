# QuestNPC 0.4.0 - вихідний код

Збірка (потрібні JDK 25 і Maven):

    mvn package

Готовий jar буде в target/QuestNPC-0.4.0.jar - скопіюй його в plugins/ сервера Paper 26.3.

Редактор квестів у грі:
  /mizkoprav editor              список квестів, створення, зміна, видалення
  Мізкоправ: Shift + ПКМ у повітря
  Меню NPC (ПКМ по NPC з Мізкоправом) -> кнопка "Квести (редактор)"
