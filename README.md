# QuestNPC

Плагін для Paper 26.3: NPC зі скінами, діалоги-дерева з гілками, торгівля та багатоетапні квести.
Усе налаштовується в грі предметом **Мізкоправ** (книга з пером), а квести описуються в `quests.yml`.

## Вимоги

- Paper 26.3, Java 25
- Онлайн-режим сервера (щоб завантажувались скіни за ніком)

## NPC і Мізкоправ

1. `/mizkoprav` видає Мізкоправ (право `questnpc.admin`).
2. ПКМ Мізкоправом по блоку: створити NPC (ім'я та нік для скіна).
3. ПКМ Мізкоправом по NPC: налаштування (ім'я і скін, діалог, угоди, перемістити, видалити).
4. ПКМ по NPC без Мізкоправа: діалог, як його бачить гравець.

## Діалог і гілки

Діалог це дерево. Кожен вузол має репліку NPC і до 5 кнопок. Кожна кнопка веде до свого вузла
(гілка), який теж має репліку і власні кнопки, і так на будь-яку глибину.

Як зробити гілку: у редакторі діалогу впиши текст кнопки і натисни **Зберегти**. Для цієї кнопки
з'явиться **Гілка: ...**, вона відкриває те, що NPC скаже далі. Порожній текст кнопки видаляє
варіант разом з усією гілкою. У текстах працюють кольори (`&a`, `&c`...) і `{player}`.

### Дія та умова кнопки

У кожної кнопки є два необов'язкові поля.

**Дія** (що станеться при кліку):

| Дія | Що робить |
|---|---|
| (порожньо) | веде до наступної репліки гілки |
| `trade` | відкриває вікно торгівлі |
| `close` | закриває діалог |
| `quest:<id>` | видає квест, потім показує репліку гілки |
| `turnin:<id>` | здає виконаний квест, потім показує репліку гілки |

**Умова** (коли кнопку видно). Кілька через кому, кнопка видима, коли виконані всі. `!` перед умовою означає «навпаки».

| Умова | Коли виконана |
|---|---|
| `new:<id>` | квест можна взяти (не брався, або виконаний і повторюваний) |
| `active:<id>` | квест у процесі |
| `ready:<id>` | усі етапи виконані, чекає здачі |
| `done:<id>` | квест виконаний |

Приклад: у привітання NPC три кнопки: «Є робота?» (дія `quest:lost_mine`, умова `new:lost_mine`),
«Ну як там?» (умова `active:lost_mine`), «Я все зробив» (дія `turnin:lost_mine`, умова `ready:lost_mine`).

## Торгівля

Налаштування NPC, потім «Угоди (торгівля)». Відкриється скриня: кожні 3 слоти поспіль це одна угода:
**ціна**, **друга ціна** (необов'язково), **товар**. До 18 угод. Клади справжні предмети (кастомні та з тегами теж).
Закрий вікно, і угоди збережуться. Кнопка діалогу з дією `trade` відкриває звичайне вікно торгівлі.

## Квести

Квести описуються у `plugins/QuestNPC/quests.yml` (там є приклад і коментарі). Після змін: `/mizkoprav reload`.
Квест це послідовність етапів, які проходяться по черзі:

| Тип етапу | Параметри | Зараховується |
|---|---|---|
| `reach` | `world`, `x`, `y`, `z`, `radius`, `height` | коли гравець у зоні (радіус по горизонталі, `height` це допуск по висоті, можна не вказувати) |
| `kill` | `entity`, `amount` | після вбивства потрібної кількості істот |
| `deliver` | `material`, `amount`, `npc` | коли гравець заговорить із NPC, маючи предмети (вони забираються) |
| `talk` | `npc` | коли гравець відкриє діалог із цим NPC |

Нагороди: `xp`, `items` (`"МАТЕРІАЛ:кількість"`), `commands` (від консолі, `{player}` це нік).
`turn-in: true` означає, що після останнього етапу квест чекає здачі (кнопка з дією `turnin:<id>`),
`false` означає, що нагорода видається одразу. `repeatable: true` дозволяє брати квест повторно.

Прогрес гравців зберігається у `progress.yml`.

## Команди

| Команда | Що робить | Право |
|---|---|---|
| `/quests` (або `/journal`) | журнал квестів із прогресом | усі |
| `/mizkoprav` або `/mizkoprav give [гравець]` | видати Мізкоправ | `questnpc.admin` |
| `/mizkoprav list` | список NPC | `questnpc.admin` |
| `/mizkoprav remove <№>` | видалити NPC | `questnpc.admin` |
| `/mizkoprav tp <№>` | телепортуватись до NPC | `questnpc.admin` |
| `/mizkoprav here` | показати свої координати для `quests.yml` | `questnpc.admin` |
| `/mizkoprav quests` | список завантажених квестів | `questnpc.admin` |
| `/mizkoprav reload` | перезавантажити `quests.yml` | `questnpc.admin` |

## Збірка на GitHub

1. Залий вміст цієї папки в корінь репозиторію (`pom.xml` має лежати в корені, папка `.github` теж).
2. Вкладка **Actions**: збірка запуститься сама після коміту.
3. Коли з'явиться зелена галочка, відкрий запуск і внизу, в **Artifacts**, завантаж `QuestNPC`.
   У ньому лежить `QuestNPC-0.3.0.jar`, його клади в `plugins`.

## Локальна збірка

```
mvn clean package
```

Готовий файл: `target/QuestNPC-0.3.0.jar`.
