# QuestNPC

Плагін для Paper 26.3: NPC зі скінами та діалогами у нативних вікнах гри.
NPC створюються й налаштовуються прямо в грі предметом **Мізкоправ** (книга з пером).

## Вимоги

- Paper 26.3, Java 25
- Онлайн-режим сервера (щоб завантажувались скіни за ніком)

## Як користуватись

1. `/mizkoprav` видає предмет Мізкоправ (право `questnpc.admin`).
2. **ПКМ Мізкоправом по блоку** відкриває вікно створення NPC: ім'я та нік гравця, чий скін взяти.
3. **ПКМ Мізкоправом по NPC** відкриває налаштування: ім'я і скін, діалог, перемістити до себе, видалити.
4. **ПКМ по NPC без Мізкоправа** відкриває діалог так, як його бачить гравець.

### Діалог

Привітання плюс до 4 варіантів відповіді. У кожного варіанта текст кнопки і відповідь NPC.
Порожній текст кнопки прибирає варіант. У текстах працюють кольори (`&a`, `&c`, `&l`...)
і `{player}` (ім'я гравця).

## Команди

| Команда | Що робить |
|---|---|
| `/mizkoprav` або `/mizkoprav give [гравець]` | видати Мізкоправ |
| `/mizkoprav list` | список NPC |
| `/mizkoprav remove <№>` | видалити NPC |
| `/mizkoprav tp <№>` | телепортуватись до NPC |

Дані зберігаються у `plugins/QuestNPC/npcs.yml`.

## Збірка на GitHub

1. Залий вміст цієї папки в корінь репозиторію (`pom.xml` має лежати в корені,
   папка `.github` теж).
2. Вкладка **Actions**: збірка запуститься сама після коміту.
3. Коли з'явиться зелена галочка, відкрий запуск і внизу, в **Artifacts**, завантаж `QuestNPC`.
   У ньому лежить `QuestNPC-0.1.0.jar`, його клади в `plugins`.

## Локальна збірка

```
mvn clean package
```

Готовий файл: `target/QuestNPC-0.1.0.jar`.
