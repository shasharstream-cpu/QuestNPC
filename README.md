# QuestNPC

NPC зі скінами, діалогами, торгівлею, квестами та лінійками квестів для Paper.
Усе налаштовується в грі Мізкоправом.

- Список команд, дій і умов діалогів, полів квестів та налаштувань: [COMMANDS.md](COMMANDS.md)
- Що нового: [CHANGELOG.md](CHANGELOG.md)

Збірка (потрібні JDK 25 і Maven): `mvn package`, готовий jar буде в `target/`.
