# QuestNPC - підказка по командах і налаштуваннях

Швидка довідка для адміністраторів. Що нового - дивіться в [CHANGELOG.md](CHANGELOG.md).

## Команди

Право для адміністраторських команд: `questnpc.admin` (за замовчуванням тільки оператори).

| Команда | Що робить |
|---|---|
| `/mizkoprav` або `/mizkoprav give [нік]` | Видає Мізкоправ вам або вказаному гравцеві |
| `/mizkoprav list` | Список усіх NPC з номерами та координатами |
| `/mizkoprav remove <№>` | Видаляє NPC за номером |
| `/mizkoprav tp <№>` | Телепортує вас до NPC |
| `/mizkoprav here` | Показує світ і координати, де ви стоїте |
| `/mizkoprav quests` | Список усіх квестів (id, назва, кількість етапів). Клік по id копіює його |
| `/mizkoprav editor` (або `quest`) | Відкриває редактор квестів у грі |
| `/mizkoprav version` | Показує версію плагіна на сервері |
| `/mizkoprav markers` | Діагностика знаків «!» і «?» над NPC: який знак має кожен NPC і чому |
| `/mizkoprav resetphrases [нік]` | Скидає одноразові фрази й повторні репліки NPC для гравця (для тестування діалогів) |
| `/mizkoprav reload` | Перезавантажує `config.yml` і `quests.yml` |
| `/npcwand` | Те саме, що `/mizkoprav` (аліас) |
| `/quests` | Журнал квестів для гравця (право не потрібне) |

## Мізкоправ (книга)

- ПКМ по блоку - створити NPC.
- ПКМ по NPC - налаштування NPC (діалог, торгівля, меню вибору, редактор квестів).
- Shift + ПКМ у повітря - редактор квестів.

## Редактор у грі

`/mizkoprav editor`, потім:

- **+ Новий квест**: достатньо написати назву, id створюється сам.
- Квест: назва, опис, досвід, предмети й команди нагороди, кулдаун, щоденне оновлення, ліміт часу.
- Кнопки квесту: «Нагорода: предмет з лівої руки», «Вимоги, видавець, відповіді NPC», «Повторюваний», «Здача NPC», «Дублювати», «Видалити», «Етапи».
- **Лінійки квестів**: групи квестів з прогресом і нагородою за всю лінійку.

Id квесту можна скопіювати кнопкою в редакторі квесту або зі списку («Скопіювати id квесту...»), а також кліком по id в `/mizkoprav quests`.

Предмети для нагород і етапів з предметом кладіть у **ліву руку** (клавіша F), бо права зайнята Мізкоправом.

### Типи етапів

| Тип | Що вимагає |
|---|---|
| Дійти до зони | прийти в точку (кнопка «Взяти мою позицію») |
| Вбити | вбити N істот певного типу |
| Віддати предмети (за назвою) | принести N предметів певного матеріалу |
| Віддати предмет з лівої руки (точний) | принести предмет з тими самими зачаруваннями й назвою |
| Поговорити | поговорити з NPC |

Для етапів з предметами номер NPC `-1` означає «забрати з інвентаря автоматично».

## Діалоги NPC

### Дії кнопки

| Дія | Що робить |
|---|---|
| (порожньо) | перейти до наступної репліки |
| `close` | закрити діалог |
| `trade` | відкрити торгівлю |
| `quest:<id>` | запропонувати квест (вікно «Прийняти / Відхилити») |
| `turnin:<id>` | здати виконаний квест |

### Умови кнопки (через кому)

| Умова | Коли кнопка видима |
|---|---|
| `new:<id>` | квест можна взяти |
| `active:<id>` | квест виконується |
| `ready:<id>` | квест виконано, лишилось здати |
| `done:<id>` | квест виконано й здано |
| `!умова` | заперечення, наприклад `!done:<id>` |
| `once` | кнопка зникає для гравця після першого натискання |
| `cd:10m` | кнопка зникає для гравця на 10 хвилин (формати: `30s`, `15m`, `2h`, `1d`) |

### Одноразові та повторні репліки самого NPC

У редакторі діалогу є поле «Репліка NPC при повторній розмові» і поле часу під ним.
Перший раз гравець чує основний текст, наступні рази повторну репліку. Якщо задано час
(`1h`, `1d` тощо), після цього NPC знову каже основний текст; `0` = повторна репліка діє завжди.

У текстах діалогів: `{player}` - нік гравця, `&` - кольори (також hex `&#ff8800`; в імені NPC ще й MiniMessage-градієнти `<gradient:#f00:#00f>Ім'я</gradient>`), а також плейсхолдери PlaceholderAPI (`%...%`).

## Кольори в текстах

Працює в іменах NPC, текстах діалогів, описах і нагородах квестів.

| Код | Колір | Код | Колір |
|---|---|---|---|
| `&0` | чорний | `&8` | темно-сірий |
| `&1` | темно-синій | `&9` | синій |
| `&2` | темно-зелений | `&a` | зелений |
| `&3` | темно-бірюзовий | `&b` | бірюзовий |
| `&4` | темно-червоний | `&c` | червоний |
| `&5` | темно-фіолетовий | `&d` | світло-фіолетовий |
| `&6` | золотий | `&e` | жовтий |
| `&7` | сірий | `&f` | білий |

Стилі: `&l` жирний, `&o` курсив, `&n` підкреслений, `&m` закреслений, `&k` мерехтливий, `&r` скинути все.
Стиль пишеться **після** кольору, бо код кольору скидає стилі: `&6&lІм'я`.

Hex-колір: `&#A923C2Ім'я` (6 символів після `#`), зі стилем: `&#A923C2&lІм'я`.

Градієнт (тільки в імені NPC, без `&`-кодів у тому ж імені):
`<gradient:#A923C2:#ffffff>Ім'я</gradient>`.

## Квести: файл `quests.yml`

Редагується в грі. При кожному збереженні з гри попередня версія копіюється в `quests.yml.bak`.

```yaml
quests:
  sokyra:
    name: "Сокира"
    description: "Опис квесту"
    repeatable: true
    turn-in: true            # після етапів квест чекає здачі NPC
    cooldown: 3600           # секунди між повторами
    daily-reset: "04:00"     # або щоденне оновлення
    time-limit: 1800         # секунди на виконання
    requires: [other_quest]  # треба виконати раніше
    excludes: [rival_quest]  # несумісні квести
    min-level: 5
    giver: 3                 # NPC, який видає квест
    accept-reply: "Дякую!"
    decline-reply: "Шкода."
    stages:
      - { type: kill, text: "Вбий зомбі", entity: ZOMBIE, amount: 3 }
    rewards:
      xp: 100
      items: ["DIAMOND:2"]
      commands: ["give {player} apple 5"]
lines:
  starter:
    name: "Початок шляху"
    quests: [sokyra]
    rewards: { xp: 300, commands: [] }
```

## Налаштування `config.yml`

| Ключ | За замовчуванням | Опис |
|---|---|---|
| `placeholders` | `true` | плейсхолдери PlaceholderAPI у діалогах |
| `bubble.enabled` | `true` | репліка NPC над головою |
| `bubble.max-length` | `140` | довші репліки обрізаються |
| `bubble.height-offset` | `0.7` | висота репліки над головою NPC |
| `menu.enabled` | `true` | меню вибору «Торгівля / Діалог / Квест» |
| `tracker.enabled` | `true` | панель прогресу квесту зверху екрана |
| `offer.confirm` | `true` | вікно «Прийняти / Відхилити» при пропозиції квесту |
| `quest.allow-cancel` | `true` | гравець може скасувати квест у журналі |
| `quest.max-active` | `0` | максимум активних квестів у гравця (0 = без ліміту) |
| `notify.title` | `true` | великий напис при виконанні квесту |
| `notify.broadcast` | `false` | повідомлення всім про виконаний квест |
| `markers.enabled` | `true` | знаки «!» і «?» над NPC |
| `markers.range` | `32.0` | відстань, на якій видно знаки |
| `markers.height-offset` | `0.9` | висота знака над головою |
| `daily.timezone` | порожньо | часовий пояс щоденних квестів, напр. `Europe/Kyiv` |

Після зміни виконайте `/mizkoprav reload`.

## Файли в `plugins/QuestNPC/`

| Файл | Що в ньому |
|---|---|
| `config.yml` | налаштування |

| `quests.yml.bak` | резервна копія перед останнім збереженням з гри |
| `npcs.yml` | NPC, діалоги, торгівля, меню вибору |
| `progress.yml` | прогрес гравців, використані фрази діалогів, панель |
